《我第一次使用 GPT-6》互動式網頁

檔案：
- index.html：網站首頁，包含 CSS、SVG 與 JavaScript，可直接用瀏覽器開啟。
- 本網站不需要建置流程或外部套件。

公開分享方式（GitHub Pages 範例）：
1. 登入 GitHub，建立一個新的公開（Public）repository。
2. 將 index.html 上傳到 repository 根目錄。
3. 開啟 repository 的 Settings → Pages。
4. 在 Build and deployment 中選擇 Deploy from a branch，分支選 main、資料夾選 /(root)，再儲存。
5. 等待 GitHub Pages 部署完成後，複製 GitHub 提供的公開網址即可分享。
